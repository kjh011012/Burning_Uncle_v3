# BurningUncle Web App

React + Vite version of the original `ui_kits/webapp` prototype.

## Run

```bash
npm install
npm run dev
```

Then open the local URL printed by Vite.

## Build

```bash
npm run build
```

## Source

- `src/App.jsx` - screen state and demo data
- `src/components/` - converted React components from the UI kit
- `src/styles.css` - global shell styles
